# Quellenvorlage

Dieser Ordner dient nur als Vorlage fuer lokale Quellordner.

Die echten Originalfolien sollen lokal unter `sources/<fach-id>/` liegen, aber wegen Urheberrecht nicht ins oeffentliche Repo, nach Vercel oder in die Dateien unter /content/ gelangen.

Empfohlene lokale Struktur:

- `sources/rabs/`
- `sources/mathe-2/`
- `sources/pum/`

Jeder Fachordner sollte eine `manifest.json` und die zugehoerigen PDF-Dateien enthalten.
